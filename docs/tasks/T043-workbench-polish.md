# T043：工作台卡片与操作反馈

2026-11-03，Issue [#99](https://github.com/wang1299/dsh-reforge/issues/99)，分支 `codex/t043-workbench-polish`，基线 `df61980`。

用户要求改善卡片结构、信息密度、图标与操作反馈。沿用 ADR040 的四个视图与 T042 主色：统计卡、经验卡和参考记录采用统一紧凑层次，元信息合并，原文与管理继续按需展开；主操作与次操作有区别。本地静态 SVG 图标配合文字，不依赖 CDN 或新增组件库。参考 Tabler/shadcn/ui 的信息组织，独立编写样式与图标。

初次读取显示加载状态；手动刷新、保存显示进行中与结果，避免重复提交。写入期间保留原表单并锁定相关控件，避免请求途中编辑或导航造成丢失。写入回执不确定、冲突、写后读取失败均保留草稿/请求标识，明确核对，不自动重试；只有成功写入并重新读到记录后刷新详情。轮询保留草稿、折叠状态和焦点。来源通过、未知、失败、停用继续有明确文字，不推导未来收益。

只改浏览器内部展示与短暂操作反馈，沿用已有 HTTP/RPC 请求、revision 与幂等请求标识，不改公共接口、领域生命周期、SQLite v9、证据、授权/预算和提炼占额，因此无新增 ADR 边界。不会改变默认学习配置、自动重放未知任务或发起模型调用。

验收：必要的延迟提交/重复点击/刷新失败回归，既有 UI 与原生客户端测试，类型/lint/构建/兼容；合成数据浏览器明暗、390px 窄屏、多卡片、空状态、键盘和实际隔离 DSH Web；稳定 SHA 独立只读评审及 Windows/Linux 两宿主版本 CI。验收记录真实结果与缺失范围，不发布 npm/Release，不改私人环境。
