# T051：独立产品官网

2026-11-05，[Issue #116](https://github.com/wang1299/dsh-reforge/issues/116)。实施前决定见 [ADR045](../decisions/045-public-website.md)。用户要求将已有品牌介绍、视频、安装说明、可运行案例与文档组织为独立对外官网。

验收：响应式中英文首页，准确安装命令和复制反馈；公开合成视频及字幕、同款可运行案例；任务导向站内文档与来源链接；移动端和键盘导航；白名单静态打包、无私有内容或模型调用；稳定提交独立只读评审和所需 CI 后合并；实际公开 URL 核验成功后再更新 GitHub Website。

实现：`website/`静态构建22个中英文入口/文档页，选取18项公开文档/媒体输入；生成白名单限定为33个文件。635处本地链接/锚点、单一标题、唯一锚点、正确语言跳转/字幕和私有路径检查通过；站内英语导航与首用/示例有完整英文，其他规范原文中可能有中文，页面明确提示。安装命令实际复制反馈通过；桌面首页与文档、390 CSS像素窗口的手机菜单/中英文首页/首用文档均已检查，无横向页面溢出。视频实际播放readyState4、时长122.178秒、中文字幕showing，无媒体错误。临时viewport已恢复。独立评审指出的正文语言链接和英语提示P2已修正，并加固了空白前缀链接协议检查；最终复审以Issue为准。

Site已注册，标识只保存到官网hosting manifest；注册URL不代表公开。稳定SHA评审、远端CI、合并、发布及实际公开URL的最终回执，以[Issue #116](https://github.com/wang1299/dsh-reforge/issues/116)的实时记录为准，不从本页源码状态推导已部署。原有alpha.2安装包、SQLite v9、历史预算和已完成试验授权均不变。本任务零模型调用。
