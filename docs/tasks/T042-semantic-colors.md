# T042：工作台主色与状态配色

2026-11-02，Issue [#97](https://github.com/wang1299/dsh-reforge/issues/97)，分支 `codex/t042-semantic-colors`，基线 `411466f`。

用户要求改善灰白界面。使用蓝紫主色区分导航/主要操作/经验提醒；绿色只用于来源检查通过等有明确文字的正向状态，琥珀用于候选/未知/待核对，红色用于明确失败及危险操作，中性灰用于停用/辅助信息。保留状态文字和所有现有事实、草稿、认证、来源、预算/授权、未知费用占额与提炼次数。

范围仅共享样式和内部展示标记，没有公共接口、证据存储或生命周期变动，沿用ADR040，无新增ADR边界。明暗色由既有宿主主题投影的color-scheme选择，宿主继续提供基础表面、字体和字号；插件主色不因宿主黑白品牌色而失去层次。未改变原生主题消息契约。

验证既有相关回归、类型/lint/构建与兼容；独立合成数据的实际浏览器明暗/390px窄屏、主要操作和状态；语义文案/主按钮的文字对比；稳定提交独立只读复核、CI及隔离同包安装保全。仅配色不新增镜像CSS断言。未运行部分与实际结果记入验收及关联PR。零付费模型调用，不发布npm/Release，不改私人环境。
