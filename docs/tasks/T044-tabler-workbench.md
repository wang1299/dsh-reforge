# T044：采用 Tabler 整体布局与风格

2026-11-03，Issue [#101](https://github.com/wang1299/dsh-reforge/issues/101)，基线 `f626b0b`，分支 `codex/t044-tabler-workbench`。

用户明确选择 Tabler。共享工作台统一采用其水平导航、独立页标题与操作区、灰底白卡、蓝色主操作、指标网格、主内容/辅助栏与卡片页眉页脚的组织方式；原有四个视图与详情钻取不变。参考 [Tabler 布局](https://docs.tabler.io/ui/layout)、[卡片](https://docs.tabler.io/ui/components/card) 与 [实际演示](https://preview.tabler.io/)，独立适配本地样式，不复制演示品牌、插画或商业数据，不引入 CDN、字体或整套运行时依赖。

清理叠加的旧样式，保持原有本地 SVG、明暗宿主主题投影、字体尺度、CSP 和认证。概览按已有记录展示四项指标、最近经验与参考记录，配置/下一步放辅助栏；未知结果、来源核对与提炼占额仍有明确文字。不虚构收益、趋势、模型费用或新授权。

本次只修改内部布局、展示样式和视图标题，不改变 HTTP/RPC、SQLite v9、领域生命周期、来源、预算或权限；沿用 ADR040，无新增公共边界 ADR。保留草稿、revision、反馈请求标识、保存锁定/未知回执和轮询焦点语义，不自动重试任何写入或未知任务。

验收：视图标题/操作入口与导航、既有客户端及原生/主题回归；类型、lint、构建、兼容；实际浏览器桌面/390px/浅深色/多记录/空记录/详情/编辑，文字对比；冻结同包审计和隔离 DSH Web 安装数据保全。稳定 SHA 独立只读评审与四组双平台/双宿主 CI 通过后合并，结果在验收及关联 PR 记录。零付费模型调用、不改私人环境、不发布 npm/Release。
