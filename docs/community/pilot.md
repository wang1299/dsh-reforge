# 外部试用 / External pilot

目标是邀请 **3–5 位真实用户**按公开文档完成首次配置和案例，记录环境差异及卡点。目前尚未获得这组外部反馈；维护者自测、录像、模型脚本不能算参与人数。

We seek 3–5 real participants to follow the public instructions and report friction. This cohort has not yet completed a trial. Maintainer tests and scripted runs are not external participants.

## 试用步骤 / Procedure

1. 阅读[版本状态](../release-status.md)，选择精确兼容的环境，不降级业务数据。
2. 从[零模型费用案例](../../examples/customer-form/README.md)开始，按[快速开始](../getting-started/quickstart.md)核对五项结果。
3. 愿意尝试真实学习时，另行自行配置 DSH 凭据、决定预算与授权；不要求使用私人代码或公开经验数据。
4. 使用 [Trial feedback 表单](https://github.com/wang1299/dsh-reforge/issues/new?template=trial-feedback.yml)记录版本、完成步骤、卡点与期望。可以只报计数/错误类别；不要上传配置、数据库、完整会话或认证 URL。
5. 维护者公开记录问题、修复链接和后续复测；未经本人同意不公布身份或引用私人反馈。不能用正面反馈替代收益对照。

Start with the no-cost synthetic example and exact compatible versions. Real learning is optional and requires your own local credentials, budget and explicit authorization. Report redacted versions, completed steps and friction using the form; no private project or learning data is required. Track fixes and retests publicly with participant consent.

## 邀请文案 / Invitation text

欢迎试用 DSH-Reforge 的首次任务案例：保存失败时保留表单输入，运行独立测试并检查经验来源。先跑零模型费用的公开合成工程，不需要提供 Key 或私人项目。我们希望了解安装、配置、理解结果时哪里卡住；失败反馈同样有用。入口：[文档](../index.md)，反馈：[试用表单](https://github.com/wang1299/dsh-reforge/issues/new?template=trial-feedback.yml)。

Try DSH-Reforge's first-task case: preserve form input on save failure, run independent checks and inspect the experience source. Begin with a no-model-cost synthetic project; no key or private project needs to be shared. We welcome installation, configuration and interpretation problems as well as successful runs.
