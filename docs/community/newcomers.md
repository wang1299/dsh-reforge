# 第一次贡献 / First contribution

先阅读 [CONTRIBUTING](../../CONTRIBUTING.md)。不需要接触真实用户数据或运行付费模型。开始前建 Issue 确认一个具体问题，附期望验收；不要为完成清单虚构缺陷或指标。

| 可做的小任务 / Small task | 怎样验收 / Acceptance |
|---|---|
| 复跑客户表单案例 / Reproduce the form example | 报告系统/版本与 2失败→2通过→3回归；仅脱敏计数 |
| 改进中英文首用说明 / Improve onboarding translations | 从新终端按步骤能跑通，版本与权限说明一致 |
| 补充真实环境排障 / Document a real setup issue | 最小复现、错误类别、确认有效的处理步骤；不含私人配置 |
| 检查窄屏与键盘可用性 / Check accessibility | 具体页面、尺寸、焦点/操作复现与预期，不只提配色意见 |

Use a small issue with reproducible acceptance. Run the public synthetic example, improve instructions, document a genuine setup failure, or inspect keyboard/narrow-screen behavior. No private database, API key or paid model run is needed. Stable changes still require the repository's checks and independent review.
