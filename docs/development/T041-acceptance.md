## 用户获得的信息

- 概览：已有经验、实际来源检查通过、待检查与提供参考的计数；未知后续结果不计成功。统计可进入对应列表，来源计数与筛选均要求完整匹配的现有测试证明。
- 经验库：来源问题、实际记录的提醒、来源状态及参考次数；详情保留独立修复检查、原文、来源、历史版本与管理。
- 参考记录：全部已保存应用、当时提供的版本、当前版本差异和最新反馈；原先首页仅显示最近五条，不能作为完整记录页。
- 学习进度：已有阶段、暂停原因、下一步、当前配置和已占用/剩余提炼次数；次数不是人民币预算，unknown 不退额或重放。不展示虚构节约、成功率或模型理解。

原生入口使用官方 conversation.view；scope 随 session key 重建，实际 sessionId 交由既有 owner RPC 核对；迟到结果在卸载后忽略。主面板和插件详情保留。新布局独立实现，仅借鉴公开插件的信息组织原则。
