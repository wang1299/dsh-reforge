# ADR060：受限修复反馈与本机研究报告

2026-11-09，T066 / [Issue #145](https://github.com/wang1299/dsh-reforge/issues/145)。先于实现，承接 ADR056–059。

## 依据与范围

T065 在提交 e069a437bff9187c91c7d6f0fd37779a24962d90 完成一次真实小规模研究：三组均 10/12，通过率差为 0 个百分点；delivery_batch 的六项均在代码准入阶段失败。旧记录没有具体 AST 拒绝原因，不能推测模型究竟使用了什么语法。42 次实际调用的峰值单价费用上界为 0.052672 元，非实际账单。本轮只做零费用工程，不复用已完成计划的剩余额度。

## 决策

1. 保留原 AST 谓词、字节/节点上限和可调用集合。验证器只新增有界协议：固定规则枚举与固定 AST 类型枚举（或 other），不回显代码、名称、异常消息或任意子进程输出。协议异常、进程失败和未识别错误仍是 unknown，不自动重试。
2. 已知准入拒绝可记录可选的结构化诊断；旧 Attempt 缺诊断仍合法且显示“未记录具体原因”。只在原有第二轮反馈中加入诊断及静态允许子集；首轮系统/任务/参考、冻结题目/验收、两轮上限、失败与未知分母不变。此反馈干预改变未来研究条件，必须重新冻结并单独申请新预算；不得改写 T065 结果。
3. 现有 Tabler 风格工作台增加“效果对照”：用户自行选择本机 study-result.json，浏览器只解析受限大小和字段，不上传、不写数据库、不授予额度、不调用模型或重放任务。纯投影模块无 Node、网络和存储依赖。只接受 schema=1 的 T065 live/fixture 报告，明确 live 与夹具。
4. 文件结构核验不等于独立核验账本或测试。重新计算三组首轮/最终通过、返工及失败/未知/未尝试；已导入汇总不一致则拒绝。分别显示研究流程、任务验收和费用状态。费用是报告中的峰值上界/未知预留，不显示为发票核对；三组同题同重复并排，支持筛选与有界明细。
5. 白名单投影只含固定任务族、组别、状态、计数和数值；不展示来源路径、会话/授权 ID、原始提案或错误文本。动态文本使用 textContent。畸形、超大、重复或不一致文件给固定错误提示，不将原文件留在页面状态；清除后释放投影。

## 验收

原准入谓词对照、真实 Python 和 AgentLoop 第二轮反馈测试；未知停止、旧记录、汇总冲突、部分报告、恶意文本/文件大小测试。类型、lint、构建、适用测试及兼容检查；实际浏览器键盘和窄屏检查。稳定提交独立只读评审。保留冻结资产、旧本机结果与账本。不新增依赖，不发布、不合并 main 或部署。工程通过不证明经验带来收益。
