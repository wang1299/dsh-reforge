# ADR040：按用户问题组织经验工作台

2026-11-02，T041 / Issue #95，基线 `6aac697c32966e6e02c9866ab5dc30b3c79faca4`。本设计先于实现提交。

用户希望参考高下载量插件的信息组织，重点理解它们向用户展示什么。参考 dsh-context 的概览与钻取、Skills Manager 的状态和列表、cost-meter 的额度透明；独立实现布局与代码，不复制品牌、资源或业务。

1. 首页回答“积累了什么、哪些需要检查、向后续任务提供了几次参考、多少次结果仍未确认”。只读汇总现有记录；来源通过不等于当前适用或未来有效，已验收反馈不等于经验带来收益。没有实际模型账单，不展示节省金额、成功率或虚构趋势。
2. 分成概览、经验库、参考记录、学习进度四个可键盘访问的标签。概览用简洁统计、当前配置摘要、待关注事项与最近经验；参考记录展示完整已保存应用及最新反馈，包含当时使用的版本。学习进度展示现有阶段、原因、下一步与提炼占额；次数不是金额预算，unknown 保留且不自动重试。
3. 经验列表优先来源问题、处理提醒、来源状态、参考次数；详情沿用问题→提醒→独立修复检查→后续参考的现有语义。原文、来源标识及高级管理按需展开。只读显示不执行验证、不请求模型、不修订旧记录。
4. DSH 会话入口注册为官方 `conversation.view` 标签，与对话/轨迹并列，移除无样式的标题栏按钮。会话视图带真实 sessionId 检查，错误放在页面内，显示正确仓库名称但不读取其他会话资料；已有独立主面板与插件配置页仍按本机 owner 权限读取配置仓库。切换 session 必须重新核对，旧 iframe 不能携带前一会话内容。
5. 页面采用宿主主题与统一控件尺度；共享面板亦保持明暗/窄屏可读。按现有 postMessage 隔离，不访问宿主业务 DOM，不新增网络或凭据通道。保留 CSP、认证、32KiB、repoId、revision、草稿、焦点和未知写入处理。
6. 不改 HTTP/RPC 的请求/返回契约、SQLite v9、核心选择、证据或授权生命周期。概览只是页面当前快照，断连须明确过期；来源缺失、全跳过、旧版本反例和未确认反馈不能显示为已证明收益。

先保留导航与新信息缺失的真实失败，再实现。验证共享客户端导航/草稿/轮询、原生会话切换和边界、两版本类型与兼容、构建/静态/完整检查，以及真实浏览器的桌面/窄屏/明暗交互。合成预览与原私人环境隔离，零付费模型调用；稳定提交独立只读评审、CI 和仓库规则通过后交付。源码改版不构成 npm/Release 发布。
