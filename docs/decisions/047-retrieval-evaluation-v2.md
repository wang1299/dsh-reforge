# ADR 047：冻结检索评测、正文覆盖候选与可复用索引

日期：2026-11-05。任务 T053，承接 #114 的离线部分；本决定先于实现提交。

## 范围

用户要求改进 AI 应用项目并取得可复查的量化结果。先完成零模型调用的检索质量、诊断和性能评价；不启动新的真实模型试验，不使用已完成的 T049 授权，不发布 npm、Release 或部署。

`bm25-v1` 的分词、评分、门槛、资格和历史策略摘要保持不变。增加可重复查询的只读预建索引，要求与旧实现逐项相同。另提供实验性 `strategy-v2`：同样的 BM25 基础分，在没有标题锚点时仅允许较强的正文覆盖，并拒绝明确仅改文档且不改运行行为的请求。它是有局限的词项启发式，不是 embedding、语义模型或语言理解。先离线评估，不接入默认 DSH 选择，不持久化新的经验/应用/授权。

## 先冻结数据，再实现

新增作者编写的 100 条合成查询，10 个任务族，各 5 正例/5 负例；4 族开发（40条），6 族留出（60条）。每个分区有自己的经验库，族和经验不跨区。正例包括直接描述、长描述、正文表达、中文及改述；负例包括无关、仅文档、过期、其他仓库和信息不足。资格是合成标签，不能当来源验证。经验都是通用提醒而非可执行证明。

完整数据在实现前提交，`test/fixtures/retrieval-v2-cases.json` SHA256 为 `d0564001694cdf6137486de31ea88bcf619991e735940e3870dc6e2b22289636`。作者可以看到留出；这不是独立盲测。允许根据开发结果调整候选；首次留出之前提交候选源码与方法摘要。首次留出后不再根据其结果调参；任何后续修改须另开评价版本。旧 36 查询和 T049 结果只作回归/诊断。

验收预先规定：开发集候选正例正确选择数高于 v1，错误提供数不高于 v1；留出无论结果好坏全部报告，不保证通过，也不据此自动替换产品默认策略。查询、标签、逐项选择、拒绝原因、命中字段、方法和数据摘要必须能复核。不给未提供经验的试验推导模型收益。留出失误完整公开，不只展示平均值。

## 指标与索引性能

报告正例正确选择/正例、错误提供/全部、负例提供/负例、精确率、拒绝数及各族/各类明细，并列分子分母。使用确定的 top-1、ID 次序打破同分；JSON 和本地 HTML 来自同一结果，HTML 对所有动态文本转义，不引用外部资源。

性能单独比较原先每次重建索引的 v1 与复用预建索引的相同 v1，在固定生成的 1千/1万文档库上预热、交错测量同一批查询，核对所有匹配完全一致；记录构建时间、单次查询 P50/P95、环境、重复数和方法。构建费用单列；不把重复查询的摊销结果说成单次冷查询提升，不把本机结果推广到其他机器。CI 只断言语义一致和报告结构，不断言加速倍数。

## 边界和后续

公开材料仅合成数据；不读用户数据库、完整会话、凭据、plan.env 或历史账本。默认 SQLite v9、资格验证、反馈、后台任务与宿主适配不变。新的索引是输入文档的快照，不暗中缓存仓库数据，调用者改变库时必须重建；结果不能反向修改索引。

T049 的两个查询单列诊断。其策略检查已知失败再改变状态，两个后续任务则处理持久化失败，适用性仍未独立证实，不能为了提高召回改成正例。#114 中更强的预登记真实模型研究仍留待后续，不以本任务关闭。
