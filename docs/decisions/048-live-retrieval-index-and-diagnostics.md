# ADR048：实际选择路径的索引复用与有界解释

2026-11-06，T054；基线 `3aa7b3d8139eb1209e272beddf1a6c9e84ad2b20`。本决定先于实现提交。

## 范围与选择

将T053已验证逐项等价的BM25索引接入 `EvolveService.select`，普通DSH请求、自动学习上下文和独立面板共用。保留默认 `evidence-v1`、`feedback-v1`、冻结 `bm25-v1` 的分词、拒绝、排序、反馈与一次应用语义，不启用实验 `strategy-v2`，不改变历史评价方法摘要。

每次选择仍重新读取来源资格、事实引用、仓库、代码/依赖、停用与当前版本负反馈，再建立合格库。索引仅缓存文本计算，不能缓存资格或反馈效用。缓存键包含服务仓库、选择模式、BM25方法、合格经验的ID/版本/验证ID/标题/正文；集合或内容改变时重建，空库清除。每个服务只保留一个索引，实例重建自然失效；不全局共享、不写磁盘。上限1万文档及2MiB文本，超限回退原版而非丢候选，并清除旧索引。构建费用与首次查询变慢的可能性单独报告。

## 解释与只读接口

选择结果/应用格式保持；在认证 `GET /api/state` 追加 `retrieval` v1 投影。每服务保留最近最多8次实际完成的选择，每次最多5个候选、每字段最多6个命中词（每词32字符）；优先保留最终选中项，其余候选按原始排名/资格排除补齐，并声明省略数。只记录任务ID、经验ID/版本、有界标题、固定原因码、评分/命中字段、缓存状态和耗时，不复制查询、完整会话、文件路径、错误原文、Key、配置或授权标识。非本仓库经验不进入新解释。

总投影再限制24KiB，超限省略较旧尝试并报告省略数；读投影返回副本，不改变缓存/选择/账本。已经应用过的任务重复调用保持旧结果，不覆盖首次选择解释；失败抛错不伪造成功记录。进程重启解释清空，界面明确“仅本次运行”，不能假装永久审计。

工作台在“参考记录”加入最近选择与展开依据：已选中/未选中、经验版本、资格/标题/正文原因；评分、缓存与耗时放入技术详情。选中不等于已送达模型、被采用或改善结果。沿用Tabler布局、明暗/窄屏、CSP、认证与原生通道，不增加重试、测试、模型或写入按钮。页面读取不重新选择。

## 测量与验收

增加内部开发者注入端口，允许同一服务链使用原版文本检索作公平对照；不暴露为DSH配置或用户操作。计量资格检查、缓存查找、构建、查询、最终排序/应用写入及选择整体；整体外部实测包含解释开销。原版构建包含在原查询时间，不能假装0构建。

真实模型调用为0；真实服务链基准仅在新的合成Git/SQLite工程运行，同一有效库、查询与独立存储、交错顺序、冷/重复请求分开、记录原始样本/分母/环境。至少覆盖1条及10条经验；不强求整体加速，Git/来源检查可能主导。仅报告实际运行规模，不将T053的1万文档微基准倍数当实际链路提速。

验收：原版与复用策略的选择/分数/拒绝完全一致；标题/策略/版本/资格变化、停用恢复、共享数据库外部修改、代码/依赖与负反馈均不能继续提供旧缓存的不合格经验。新增只读投影有界、无私人配置/路径、重启清空，GET不创建任务/应用/授权。验证共享面板与实际官方宿主脚本请求、两精确版本四组合CI、类型/静态/构建/兼容及稳定SHA独立只读评审。

SQLite v9、财务账本、未知费用、提炼已用次数及用户历史保留；本轮不读私人体验数据，不调用模型，不发布npm/Release，不主动部署。跨语言/改述及真实收益仍归后续新数据/新研究。
