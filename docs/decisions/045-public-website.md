# ADR045：独立官网与现有文档同源

2026-11-05，实施前决定。[Issue #116](https://github.com/wang1299/dsh-reforge/issues/116)，用户明确要求按此前介绍建设对外独立官网，参考 Iris 的“展示首页＋文档导航”，沿用 Reforge 品牌。

官网源码放在本仓库 `website/`，静态构建生成展示首页与任务导向文档；复用公开品牌图、合成演示视频、客户表单示例和仓库文档。中英文入口、精确 alpha.2 安装命令、可访问导航、复制反馈、窄屏布局和来源链接共同验收。站内文档从明确白名单的现有 Markdown 生成，其他相对链接回到 GitHub；构建不得扫描、复制私人工作区、经验库、配置或凭据。文档渲染拒绝原始 HTML 和不安全链接协议。

使用 Sites 支持的源码、静态打包与发布流程。Site 标识存于 `website/.openai/hosting.json`，只创建一次；构建输出、发布检出和回执留在忽略目录。隔离发布检出只接收已审查官网源码/白名单输出，不在主仓库执行 Sites helper 的全量 stage，不上传学习数据。用户要求的是对外官网，目标受众为公众；先完成代码、实际浏览器验证、稳定 SHA 的独立只读评审、所需 CI 和合并，再按原生工具支持公开发布并核对实际 URL，成功后更新仓库 Website。不将本地预览、创建 Site 或预期 URL 当作公开部署成功。

页面不调用模型，不收集账号、Key、会话、经验或遥测，不新增预算。明确实验版、精确支持两宿主、学习默认关闭、开启后的执行与模型共享边界。合成视频、真实自动闭环、未来任务收益和市场收录分别表述；不得编造效果、用户、下载量或官方背书。已发布 npm/Release 不重打包、不变更账户安全设置。后续改动须重新构建检查并保留可回退的发布版本。
