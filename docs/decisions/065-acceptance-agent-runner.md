# ADR065：验收驱动的受限修复 Agent 与任务工具契约

2026-11-16，T073 / [Issue #158](https://github.com/wang1299/dsh-reforge/issues/158)。先于实现；从未合并 PR157 的 9c2e24f 分支。保留插件定位，在显式开发演练入口连接规划、原生 Tool Calling、上下文与已有来源验证检索，不改默认 DSH、SQLite v9、旧授权或费用账本。

## 决策与范围

1. DSH 提供模型循环/原生工具运输；新核心不导入 SDK，负责计划准入、步骤状态、执行结果核对和终止。模型提交有界结构化 DAG（最多8步），动作只有读取、复现、修补和验证；依赖须指向先前步骤，修补必须依赖读取及复现，验证依赖修补，最终验证覆盖全部步骤。计划不能修改 owner 固定的目标、文件和独立验收。步骤成功由宿主记录，完成文本与 idle 不验收。
2. 计划、读取、修补、测试四工具均严格校验输入和计划 revision。每次调用绑定 ID 与请求摘要；本进程相同 ID/相同参数返回原回执，相同 ID/不同参数拒绝。并发串行化，最多32次不同调用、最多2次重规划。未知读写/测试结果立即停止，不自动重试；不提供跨进程 exactly-once 或自动恢复，重启没有接续入口。只在确定验证失败后允许重规划，新计划清除步骤状态，初始复现依据仍绑定冻结原始快照。
3. 文件端口仅能读写新建合成工程的 target.py，不能选择目录/命令、改测试或配置。修补以原文摘要做比较替换，必须先读且声明同一版本。沿用已有 owned-path/原子写入、受限 repair 函数 AST 准入和有资源限制的 Python worker；只执行作者受控合成任务，不声称通用恶意代码沙箱。测试端口固定外部验收及原始快照，回执绑定代码/验收摘要、完整预期测试ID、退出码及逐项状态；缺项、跳过、异常、漂移均不接受。
4. 每次请求通过只读工具可获取当前上下文投影：固定目标/验收身份、当前完整计划状态/终止原因必需保留，最新结构化回执有界；通过现有来源/条件检查选中的经验 notice 作为不可拆原子包加入。最终序列化 UTF-8 字节预算只覆盖此投影，不声称覆盖 DSH 全历史或模型 Token。必需包超限拒绝；经验放不下则省略并给原因。工具结果及代码只在运行期和新合成目标文件使用，持久报告只有计数、固定原因、摘要和步骤状态，不存完整会话/代码/任意输出。
5. 既有 EvolveService 负责演练新源库的来源资格和检索，再由既有上下文编译器保留事实引用；新层不以字符串/相似度授予来源资格，不改变 T072 冻结参数和首轮结果。多候选语义排序与反例学习属于后续实验，本轮不把已有离线原型宣称成默认产品能力。

## 验证和复现

- 先实现纯核心与严格失败控制，再通过官方 AgentLoop + 原生工具调用的脚本 adapter 验证完整数据流。脚本按实际工具回执推进、从真实读取获取版本；参考修复只属于明确标注的演练，不能证明模型规划或任务收益。
- 新建源库使用已有独立原始失败/修复/回归验证；演练目标执行真实受限 pytest。happy、已知失败后重规划、自称完成、未知执行、过期调用、ID冲突、并发/预算及来源漂移均要有控制。
- 本轮无真实 provider、Key 读取或付费请求。安装既有仓库所带固定 Python wheels 不联网；保留旧研究/授权/unknown，不默认启动任何学习任务。
- 目标检查、typecheck/lint/build、完整测试/compat、两平台两精确宿主版本矩阵、稳定 SHA 独立只读审查及 Draft PR；不会合并父 PR、发布包/Release或部署。设计/演练通过不等于实际 Agent 效果。

后续真实模型入口必须另立冻结任务和预算/安全审查；本入口不能接收 endpoint、Key 或任意 provider 参数。
