# ADR063：有来源约束的 Agent 上下文编译器

2026-11-15，T071 / [Issue #154](https://github.com/wang1299/dsh-reforge/issues/154)。先于实现；ADR062由独立T069分支保留。本任务直接基于main1df95d7，不合并或改写未完成的其他任务。

## 目标与依据

面向Agent岗位的项目应解释上下文决策、执行边界与验证结果。参考[公开项目CV Generator](https://ckcinnabar.github.io/projects/cv-generate.html)按需读取/验证的组织，[GenomicsCopilot](https://github.com/ankurgenomics/agentic-genomics)的确定计算与模型判断分工，以及[Perplexity岗位](https://jobs.ashbyhq.com/Perplexity/f3814af2-55a3-49a5-b0cb-67199a2a45fb)强调的上下文/技能效率。它们是设计参考，作者自述的收益不属于本项目。

DSH负责AgentLoop；本插件负责经验选择和实际提供的记忆notice。现有来源资格、单经验上限、人工条件veto和SQLite v9保留。新增自己的有界、可解释上下文编译，不新增编排框架或模型调用。

## 决策

1. 配置可显式启用`memoryContext:{policy:"evidence-mmr-v1",maxNoticeBytes:8192}`；范围512–65536字节。未配置时既有选择、返回及notice逐字保持。只约束本插件自动/owner-confirmed请求的经验notice，不限制整段模型历史、工具输出或模型费用；不是精确Token计数。
2. 原选择器先执行同样的最新来源、引用、仓库、代码/依赖、反馈及owner条件检查，不为预算改排序或补选别的经验。策略、经验/应用/来源身份和精确版本、完整适用条件及风险提示为必需原子材料。必需材料超预算时拒绝提供，且在写Application前停止。
3. 可选材料仅为原始observedFacts及该条事实的完整有效引用。每个事实/引用组原子保留或省略，不截断/改写文字，不把推断或建议变成事实。来源完整不表示语义真或后续收益。
4. 固定算法：复用现有NFKC/camel/英文词/CJK二元词切分；相关性为查询词覆盖比例，冗余为与已选事实的最大Jaccard。借鉴[MMR](https://aclanthology.org/X98-1025/)的相关性与新颖性折中，使用`(0.7*relevance-0.3*redundancy)/新增序列化字节`贪心选择正收益且可容纳的单位，平分按原事实索引。无相关词不补无关事实；归一化完全重复事实只保留第一项。最多12事实，决策有界；不声称全局最优或近似保证。
5. 用最终UTF-8序列化文本核对上限，包含警告、JSON、条件和引用；不靠字符数或Token估计冒充硬预算。保留原始经验和所有未提供材料，只在内存生成投影。trace只保存状态/预算/字节/索引/固定省略原因等有限元数据，最多复用原8条进程内记录，不保存额外对话或私人原文。
6. 自动与owner确认请求经相同编译入口；显式begin工具仍沿用旧接口，其原完整工具输出不在此notice预算内。关闭共享时不生成或提供经验。真实AgentLoop验收读取实际GenerateOptions，确认notice及预算拒选的应用记录，不把idle当送达或任务成功。

## 评测与权限

先固定合成数据和算法，再首次运行对照：完整来源事实包、同预算源顺序、同预算相关性密度、同预算MMR密度。报告字节、预算超限、可用事实/不同标签覆盖、引用完整性、冗余及拒选，所有方法与失败/代价保留。标签为作者可见合成标签，不是独立盲测或Agent收益；默认旧notice单独列出，不能把新增事实的信息优势归因算法。

测试原子来源、UTF-8/转义成本、紧预算、零相关、重复、条件与引用漂移、共享关闭、旧行为、实际Agent请求；完整check/compat和两平台两宿主CI/安装及稳定SHA独立只读审查。零付费，不复用旧计划、预算或Key，不改私人配置/原数据；发布/部署仍需具体授权。
