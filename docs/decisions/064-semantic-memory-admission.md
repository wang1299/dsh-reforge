# ADR064：本地语义准入与拒选的记忆规划器

2026-11-16，T072 / [Issue #156](https://github.com/wang1299/dsh-reforge/issues/156)。基于未合并PR155的77435fe，新增分支codex/t072-semantic-memory-planner；不合并、部署或发布父分支。本ADR在实现和首次神经评分前提交。

## 问题和边界

T071在同预算下MMR相关facet16/36低于源顺序18/36，短的词面相关无关事实仍会进入上下文。本轮先完成新任务集和语义准入规划器的零付费本地实验。DSH默认选择、宿主接线、SQLite v9、私人经验、授权和真实任务研究保持原状；不把离线候选装成生产功能或Agent收益。

## 决策

1. 冻结12个作者可见的不同任务族，开发/评测各6族，每族2正4负查询，共72查询；每种语言均含行为修复、文档请求、矛盾需求各一条。事实按固定族索引循环移位，标签随事实移动，不根据评分选择顺序。每族独立Python原始、参考和错误实现及外部pytest契约。标签表达作者的适用性判断，实际契约检查验证代码行为，不证明自然语言事实或策略真，也不冒充已存入Store的来源资格；通用编程原语可跨族重叠，不声称外部盲测。
2. 复用T056原始固定revision、权重/分词器摘要、128-token无截断、384维mean/L2/round7本地CPU模型和EmbeddingPort。只导出本轮固定公开文本；不开放任意文件/配置输入、不连接模型API、不存私人查询。向量绑定模型、数据、namespace、ID、revision和精确文本，缺失/失效/非有限向量拒绝整次规划，不回退到未经检查的内容。
3. 新纯规划器接收已由调用者核对来源/代码/依赖/owner条件的单一经验。它先验证原编译器必需包与完整引用，随后按文档余弦阈值准入；另一消融臂增加固定“行为修复”相对“文档/外观修改”的意图锚点余弦差阈值。锚点是方法常量，不是标签/证明；局部向量相似度不能证明逻辑蕴含、否定或适用条件。
4. 对通过准入的事实按事实余弦阈值生成索引白名单，再交给T071源顺序预算打包。新增可选allowedFacts输入，只允许原索引的严格有效子集；不重写事实/引用/版本或重排索引，白名单可容纳没有词面重叠的改述。未传白名单时T071原算法与结果逐字保留。必需条件仍原子保留；无法容纳、无准入事实或证据绑定问题返回空notice。过程只读，不写Application/Store。
5. 对照为原源顺序、原MMR、文档余弦准入、文档余弦+意图差准入。相同输入、事实、必需字段与预算；不让候选看到额外任务标签、参考代码或pytest答案。固定开发网格：文档阈值[0.25,0.35,0.45,0.55,0.65]、事实阈值[0.25,0.4,0.55]，意图差[0,0.05,0.1]。每个候选臂至少保留ceil(0.75*开发正例)正确提供，再最小化负例误供、最大化正例相关facet、最小化无关事实、最大化正确提供，最后按网格顺序；无可行配置保存全网格并停止评测。
6. 先提交完整方法/数据/实现并审查，再生成和评分开发向量；只按开发校准。将完整网格、参数和方法/模型/数据摘要提交冻结，干净树才允许首次生成/评分评测向量。保留首次全部逐条结果、拒选导致的漏选、开发失败及代价；不按评测结果改题/阈值。公开合成向量仅支持CI评分重放，不能冒充每台CI都运行了神经推理。

预审后、首次评分前补清计数：正确提供要求标签适用、非空有效notice且至少含一条相关事实；只有mandatory策略的正例单列“无相关事实”，算漏选。负例误供指不适用却提供notice。开发75%下限按此正确提供定义；按语言×需求类型报告全部分层。初稿48查询和所有事实固定位置的局限经预审后在任何推理前修订为上述72查询；原冻结提交保留，不冒充从未改动。relative_path仅声明POSIX斜杠路径，缓存值控制用身份断言区分0与False。

## 验收与后续

测试越界白名单、原文/全引用原子性、预算/默认兼容、向量身份/文本漂移/缺失、开发校准约束和拒选。实际执行12族×3契约控制并保留失败；完整check/compat、稳定SHA独立只读审查和增量Draft PR。对照报告正确提供、误供、漏选、正例可用facet覆盖、无关事实、字节、引用绑定和本地推理成本。没有真实Agent成功率、返工或现金收益结论。

宿主策略接线与真实模型执行属于后续阶段，需先证明离线取舍并独立审查；真实调用按新的冻结计划与明确预算授权，不复用任何历史许可。本轮不修改公开包/Release/官网或账户设置。
