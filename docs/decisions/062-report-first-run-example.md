# ADR062：先读合成示例，再导入本机报告

2026-11-09，T069 / [Issue #151](https://github.com/wang1299/dsh-reforge/issues/151)。先于公开界面实现，承接ADR060–061。

## 依据

所有者在原生合成宿主试读时找不到长路径的测试文件；通过本机下载再导入才完成手工核对。这证明了文件定位摩擦，不是解析失败或真人可用性研究。参考[Langfuse的示例项目入口](https://langfuse.com/docs/demo)“先探索，再接入自己的数据”的组织方式；不调用其服务、不复制代码，也不据此宣称改善已被测量。

## 决策

1. 效果对照页增加明确的“查看合成示例”入口，与本机JSON导入并列。示例是源码内自包含、有限且每次新建的展示投影，不是研究报告、原始账本、模型响应或验收证据；只在页面内存中存在。它不获得服务端、网络、存储、执行、预算或模型能力，不下载或自动导入私人文件。
2. 示例使用相同固定36项/每组12项的阅读结构，预制成功、返工、失败、一次未知和未尝试状态，明确显示“示例/模拟/未运行任务”。三组固定分母和差值不作为效果结论。金额及时间均为合成教学数据，未知占额仍显示且不代表用户账户。
3. 页面内部显式区分示例与本机导入。示例不显示伪造源码SHA、真实文件核验或真实费用文案；本机导入继续走原有大小/字段/汇总核验。文件中的scope不能将导入变成内置示例或升级为独立来源证明。
4. 载入示例、开始新导入或清除都会使旧异步读取失效。切换清除旧投影/筛选/计时/错误，迟到的文件成功或失败不能覆盖新示例。刷新其他工作台数据不能改写本页报告。键盘焦点和状态反馈可用；继续采用既有Tabler布局、主题和隔离CSP，不新增依赖。
5. 增加简短阅读顺序，并为官网及文档中旧试验加日期；最新源码研究与已发布alpha.2分开。保留所有历史研究、固定验收、预算、未知占额和已用授权，不重新运行模型，不改变schema或原准入规则。

## 验收与边界

实际嵌入脚本的示例/导入/清除/迟到读取状态转换及无写入检查；示例固定分母/模拟标识/未知占额与缺失计时对照；独立与精确sandbox/CSP合成宿主实际点击、键盘、深色和390px检查；类型、lint、构建、兼容和适当CI；稳定提交独立只读审查。原生合成宿主不冒充完整DSH应用或真人试用，点击数量不是节省工时。后续反馈干预仍需新冻结实验及单独预算，不能用示例数字替代真实任务收益。
