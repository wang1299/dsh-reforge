# ADR043：真实模型自动闭环与十元以内的小规模对照

2026-11-04，T049 / [Issue #110](https://github.com/wang1299/dsh-reforge/issues/110)，上级 T046 / #105。先于试验实现与任何付费调用提交。owner 明确授权本轮新增人民币 **10 元上限**；不使用或重置任何历史预算、unknown、grant 或数据。

## 财务与传输边界

采用官方 `deepseek-flash`（当前官方版本 DeepSeek-V4.1-Flash-1017），非思考、每次请求输出上限2048、无自动重试、顺序调用。只请求官方固定 `https://api.deepseek.com/anthropic/v1/messages`，不允许重定向、图片/文件、Search/Fetch、server tools、任意扩展或模型目录请求。凭据经 DSH 本机凭据服务仅在内存解析，不复制或打印 Key/私人配置。

价格以2026-11-04核对的[官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)为依据，统一用峰值输入2元/百万token、输出8元/百万token，所有输入按未命中估算，不以缓存折扣减少占额。官方说明部分生态请求的有效max_tokens可能扩大；调用前按完整模型边界保守占额：输入1,100,000、输出393,216，共 **5,345,728微元（5.345728元）**。累计已结算上界+未结算占额+新占额不得超过10,000,000微元；最多32个逻辑请求，一次只能一个在途。

新增独立、独占锁、原子/fsync账本，调用前先持久化占额。只在HTTP200、完整SSE终止、合法最终usage且没有服务器工具费用时，用最终input+cache_read+cache_creation及output按峰价结算；不把起始usage与最终累计值相加，见[官方计量说明](https://api-docs.deepseek.com/guides/anthropic_api/#streaming-and-token-usage)。服务端不支持的字段/费档、非零服务器工具计数、计量越界、超时、网络错误、消费者取消、断流或持久化失败均保留完整占额并阻止后续付费请求。重启不能重试或退额；离线负例须证明这一点。报告的是保守token费用上界，不冒充服务商账单。

预付费独立评审后的存储决定（实现前追加）：原型“临时JSON fsync后rename”未覆盖Windows目录元数据掉电边界，改为**全新独立SQLite账本**（自身schema1，与插件v9无关），DELETE journal、synchronous=EXTRA，SQLite事务提交占额后才允许网络请求。依赖SQLite的[原子提交](https://www.sqlite.org/atomiccommit.html)和[同步保证](https://www.sqlite.org/pragma.html#pragma_synchronous)，不自行实现跨平台目录刷盘；不读取/迁移旧JSON预算。所有usage位置先核对费用字段/费档，只用完整终止帧的最终累计token结算；SSE帧缺终止空行亦按未知保留。尚未发生本轮任何付费调用。

最终入口评审后的决定（实现前追加）：正式授权改用仓库内**唯一固定位置** `.probe-work/t049-authorized-budget.sqlite`，财政schema2同一事务保存授权run/计划摘要、不可重放的开始状态和费用占额；所有live入口只接受这一账本及已开始的同一计划，不以可丢失的JSON定位/开始标记授予新额度。旧未付费原型schema1不迁移。冻结全部实际执行的dist/src、dist/scripts与宿主运行依赖文件，除源文件摘要外核对编译产物；比较最后一项即使已记12次调用，仍须无unknown占额/停止原因才能计完整。负面任务结果仍保留为有效试验结果，不冒充成功。资格检查使用不刷新index的Git读取；持续固定HEAD及暂存内容，自动闭环另外核对index原始字节。所有改动在首次付费前完成。

## 实际自动闭环

使用新隔离profile，通过官方安装操作安装冻结tgz，所有官方SDK均从同一个固定0.2.1-rc.5宿主图解析。实际Loader执行安装包，真实官方AgentLoop、DeepSeekAdapter、SessionStore、ToolRuntime、SystemPrompt及本机凭据服务协作，不以脚本模型代替真实API。测试专用写入工具只允许对一个新的合成Python函数提交有界代码，AST约束无导入、文件/网络/进程操作；补丁由真实模型生成，不提供预制修复。它是受控组件集成，不冒充完整Desktop UI或通用工具能力。

正常直接请求要求修复账务事务异常未恢复余额，提供原始函数及明确纠正；不得调用显式evolve工具。自动采集未提交快照 → 原始失败/修复通过/回归 → 一次明确授权的提炼 → 自动独立再验。只有真实pytest及数据库状态满足，才报告来源通过。随后新正常请求的实际provider输入必须包含实际所选经验，且应用记录一致；提供参考不等于采用或收益。idle、完成提示及模型自评只作为等待边界。

只对新合成工程授权执行/共享/后台/自动学习，新的grant最多1次，授权与财务账本相互独立。使用内存会话，不持久化完整对话、任意工具输出或模型原始响应；只保存有界源文件、来源/测试状态、token/占额回执、ID/摘要和阶段计数。原主仓库/默认Desktop/旧体验库均不改。

## 预先固定的小规模收益试验

在付费前固定全部合成源码、独立验收、提示、顺序、模型与包摘要。两项未进入本轮学习的任务：库存持久化失败恢复remaining；客户表单持久化失败保留草稿、成功后清空。两次重复、三组，共12次单次生成。未见指本轮试验模型未收到目标源码/验收于学习阶段，不声称模型训练语料未知。

三组均用相同原始任务、模型、非思考设置和2048输出上限：无记忆；对同一冻结来源文本做普通词项检索；Reforge按实际仓库/代码/依赖/相关度选择经验。没有匹配就不提供，不人为强制选中。普通检索不检查来源资格或scope，不使用评价答案；Reforge返回实际版本并记录应用。各次请求是独立新上下文，不把前一次答案带入后一次。固定交错顺序分散时段影响，不见结果后调提示、换题或补正面样本。

每次仅允许一次有界代码生成与固定外部验收/回归，无自动修复回合或人工补丁。记录全部测试通过率、负路径/错误复用、拒选/提供次数、超时/无效代码、需返工案例和实际额外编辑（预设为0）；实际返工成本未测，不填“节省返工”。报告每组token/保守费用、实际学习开销及含学习开销的单独合计；源学习复用两组时说明分摊假设，不能重复统计实际总扣费。n=4/组仅是可复现探索，不作统计显著性或普遍收益结论。全通过、全失败或没有改善均完整公开。

任何未知费用会暂停剩余付费阶段；已完成结果与缺失项如实记录，不借新grant或新账本规避。实施先离线验证预算/传输/AST/验收和完整流程；冻结实际计划后才运行。稳定提交独立评审、CI、文档与发行继续分开完成。
