## 本轮交付

将现有真实运行说明改为紧凑主从检查器：任务摘要搜索、全部/选中/未选中筛选、最新条目默认选中，保留选择与展开状态。详情先展示结论与可采取的下一步，再展示候选数/合格数、候选原因及当前经验入口；耗时/分数继续渐进展开。不能把候选截断数当全库统计，不能把选中说成已送达/采用/成功，缺少候选不能推断唯一拒选原因。

只读使用已有retrieval状态；不新增选择/写库请求、不修改默认检索、SQLitev9、账本/授权或原始历史。搜索本机当前快照，不持久化/上报查询。轮询不重置用户选择或抢焦点；条目出内存保留范围后回退到当前筛选内最新项并明确范围。窄屏采用上下布局，沿用原生主题变量，支持键盘和清楚的选中状态。

UI验收：真实合成来源/选择服务驱动的本地面板，对比改前/改后查看最新拒选候选并打开经验的实际点击数；不将脚本步骤当真人时长或认知收益。保留同一工作负载、桌面/390px截图、搜索/筛选/轮询/空状态/只读与安全文本结果。必要针对测试、全check/compat、四组合CI和稳定SHA独立只读审查后合并，不发包/Release/部署。
