# DSH-Reforge v0.1.0-alpha.3

实验性插件，支持 DSH `0.2.0-rc.2` 和 `0.2.1-rc.5`，需要 Node.js ≥24.10。安装到自己的 DSH profile 时可锁定版本。

```sh
dsh plugin --profile web add dsh-reforge@0.1.0-alpha.3
```

| 功能 | 使用入口 |
| --- | --- |
| 带来源和字节预算的经验上下文 | 所有者在配置中显式启用 `memoryContext`。[配置与限制](https://github.com/wang1299/dsh-reforge/blob/v0.1.0-alpha.3/docs/agent-context.md) |
| 本地语义准入与拒选 | 从 `dsh-reforge/semantic-memory` 导入规划器，或运行下方的冻结留出集重放。使用公开合成向量，无需下载模型。 |
| 验收驱动的修复 Agent | 包中包含修复控制器、原生工具适配器和可运行示例。脚本生成模型响应，四种原生任务工具和独立 pytest 验收实际执行。 |
| 经验维护检查 | 所有者在停机后使用 `dsh-reforge memory-review --config <file> --stopped` 只读检查来源和当前条件。 |
| 代码变动后的复验 | 在面板预览并确认手工修复的复验，保留已有报告。维护报告标出同页共享测试证明的经验。[操作说明](https://github.com/wang1299/dsh-reforge/blob/v0.1.0-alpha.3/docs/memory-maintenance.md) |

### 从安装包运行示例 / Run the packaged examples

在一个新的空目录解包并安装示例依赖。修复演练使用 Git、Python 3.10 和 pytest 9.1.1，并从固定地址下载带摘要的 Python 依赖。演练仅在解包目录内创建临时合成仓库。语义重放读取包内数据，全程离线。两个示例均无需模型 Key。

```sh
npm pack dsh-reforge@0.1.0-alpha.3
tar -xzf dsh-reforge-0.1.0-alpha.3.tgz
cd package
npm install --include=dev --ignore-scripts
npm run example:semantic-memory
npm run example:repair-agent -- happy
```

The package includes opt-in context packing, semantic admission, the scripted repair Agent, read-only memory review, and owner-confirmed revalidation. The commands above run the examples from the extracted tarball. The repair example also accepts `replan`, `self_report` and `unknown`. In its frozen 36-query comparison, intent gating avoided 11 false offers and lost two positives versus cosine alone. Downstream task benefits require separate evidence.

学习默认关闭。已有 SQLite v9 数据、预算账本、未知费用占额和已用提炼次数沿用原配置。发布制品及下载核对见[发行记录 #167](https://github.com/wang1299/dsh-reforge/issues/167)。
