# DSH-Reforge v0.1.0-alpha.2

实验性 alpha / Experimental alpha. 精确支持 DSH **0.2.0-rc.2、0.2.1-rc.5** 与 Node ≥24.10；其他宿主继续拒绝。安装：

```sh
dsh plugin --profile web add dsh-reforge@0.1.0-alpha.2
```

- 独立DSH适配层、固定SDK依赖图和Windows/Linux双宿主矩阵；修复新版认证owner handle兼容。
- Tabler风格工作台，学习进度、经验、来源与应用记录，以及清晰的操作状态。
- [同款完整客户表单工程](https://github.com/wang1299/dsh-reforge/tree/main/examples/customer-form)、中英文首次配置与验收导航、FAQ、安全/新人/外部试用入口。
- 保守setup、只读doctor、停机备份和恢复到新目录。保留SQLite v9、私有快照、历史unknown、预算与已用提炼次数；不自动重放未知任务。
- [真实模型小规模报告](https://github.com/wang1299/dsh-reforge/tree/main/docs/evaluation/t049-20261104)：受限合成自动闭环通过；12项对照三组均4/4，但两检索都拒选，未测到实际使用经验的效果。16请求费用保守上界0.037128元，未知占额0。录像仍是零模型费用的显式案例，不冒充真实模型录屏。

Upgrades include the exact two-host adapter/matrix, the Tabler-style workbench, the runnable matching example, bilingual navigation and conservative owner setup/diagnostics/backup/restore. The actual bounded synthetic automatic loop passed. Both retrieval arms abstained in all held-out trials; the 4/4 results per arm do not establish a memory benefit. Real external participation remains pending.

**升级前 / Before upgrading:** stop DSH and follow [data operations](https://github.com/wang1299/dsh-reforge/blob/main/docs/maintenance.md). Keep private backups and unknown liabilities; never reset grants or downgrade a live database. Alpha.1 remains immutable. Keys stay in local DSH configuration. Learning/execution/sharing require owner authorization; model dialogue and extraction may cost money.

此Release的tgz取自npm真实注册表；`SHA256SUMS`与`release.json`绑定对应源提交和制品。公开安装与附件核验以[版本状态](https://github.com/wang1299/dsh-reforge/blob/main/docs/release-status.md)和[Issue #113](https://github.com/wang1299/dsh-reforge/issues/113)为准。此社区插件不代表DeepSeek官方审核或推荐。
